# New-York-Taxi---Capstone-Project-1

## Project Overview 

This projects apply an end-to-end ETL (Extract, transform & load) data pipeline using python 

The pipeline automatically: 
- Extracts NYC Yellow Taxi trip data
- Transform dataset
- Runs inside a Docker container

## Outputs 
Generate: 
- Clean transform dataset
- valid and also quarantine datasets
- pipeline logs

## programmes and software used in this project 
- Python
- Pandas
- PyArrow
- Docker
- Docker Compose
- Powershell
